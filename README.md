# مشوارك — Meshwarko

تطبيق مصري لطلب المشاوير يربط الركاب بالسائقين داخل المحافظة والمركز، يدعم التوكتوك، التروسيكل، الملاكي، الميكروباص، التمناية، النقل، وموتوسيكل الدليفري.

---

## 📱 المميزات

### للركاب
- تحديد مكان القيام والوصول على الخريطة أو بالبحث.
- اختيار نوع المركبة.
- سعر مقترح تلقائي حسب المسافة والزمن.
- تفاوض على السعر مع السائقين (عرض / قبول / رفض).
- تتبع السائق لحظة بلحظة على الخريطة.
- محادثة فورية مع السائق.
- تقييم الرحلة.
- سجل الرحلات والمحفظة.

### للسائقين
- استقبال طلبات جديدة في منطقتهم فقط.
- اقتراح سعر مختلف أو قبول السعر المطلوب.
- بدء / إنهاء الرحلة تلقائياً بناءً على الموقع.
- نبذة كاملة عن الراكب بعد القبول.
- محفظة بأرباح الرحلات.
- سجل الرحلات.

### للإدارة
- لوحة تحكم كاملة.
- إدارة المستخدمين (حظر / فك / حذف / ترقية أدمن).
- إدارة الرحلات (إلغاء).
- مراقبة السائقين المتصلين.
- إحصائيات مباشرة.
